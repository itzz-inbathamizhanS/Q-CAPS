# Track C — Advanced / Quantum & PQC Specialist
**Entry profile:** Strong technical background in computing, mathematics, cybersecurity, cryptography, quantum computing, or related engineering. Designed for senior professionals, postgraduate students, engineers, and researchers.

## Modules in this track
1. `C1` — Advanced Quantum Information
2. `C2` — Advanced Quantum Algorithms
3. `C3` — Quantum Error Correction
4. `C4` — Quantum Networking
5. `C5` — Quantum Communications
6. `C6` — Quantum Key Distribution
7. `C7` — Advanced Cryptography
8. `C8` — PQC Mathematics
9. `C9` — PQC Implementation Engineering
10. `C10` — PQC Attack Surface
11. `C11` — PQC Defense Engineering

## Advanced Capstones (choose one)
- PQC implementation security evaluation
- Quantum network architecture
- Secure quantum communication system

## Certificates
**QCE** — Quantum Computing Engineer, **PQC-E** — Post-Quantum Cryptography Engineer, **QNE** — Quantum Networking Engineer (awarded based on which capstone path is completed).

## How this fits Q-CAPS
Track C is where the platform stops teaching "how to migrate" and starts teaching "how to build and break" — implementation security, side-channel attacks, and formal defense engineering. This is specialist-level content, most relevant to the research/developer labs described in the original Q-CAPS master checkpoint.
