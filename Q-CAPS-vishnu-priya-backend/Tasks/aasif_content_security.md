# Role: Cryptography Content, Labs & Security
**Team Member:** Aasif
**Focus:** Cisco-Style Course Creation, Interactive Learning, Quiz Engine Logic, Authentication

## Exactly What You Need to Build
You are the Subject Matter Expert (SME). You must build a comprehensive, full-scale learning course modeled after **Cisco Networking Academy**. Your courses cannot just be "walls of text." They must be broken down section-by-section, utilizing visual aids, interactive elements, and mid-section knowledge checks to ensure users actually understand Post-Quantum Cryptography (PQC). You are also responsible for building the secure Login/Signup authentication system to ensure Q-CAPS itself is unhackable.

## How to Use AI to Help You Build It
You can use AI to help you design interactive course modules and generate accurate cryptographic content.
**Example Prompts to give your AI:**
*   *"Design a Cisco-style interactive course module on NIST ML-KEM. Break it down into 3 sub-sections. Instead of just text, describe what visual diagram or interactive slider I should include in each section."*
*   *"Write a secure Node.js authentication flow using JWTs (JSON Web Tokens) and bcrypt to hash user passwords before storing them in a database."*

## Your Individual Sub-Segmented Plan

### Phase 1: Interactive Course Design (Cisco Model) (Days 1-3)
*   **Sub-task 1.1:** Outline the full, comprehensive A-to-Z Curriculum. You cannot just jump into advanced math; you must start from the absolute beginning so anyone can learn. 
    *   *Module 1:* What is Cybersecurity? (Basics of classical encryption, RSA, ECC).
    *   *Module 2:* The Full Quantum Concept (What is a Qubit? Superposition, Entanglement, and how Quantum Computers work).
    *   *Module 3:* The Threat & Mitigation (Shor's Algorithm, PQC, and NIST standards like ML-KEM).
*   **Sub-task 1.2:** For each section, design visual/interactive requirements (e.g., "Insert an interactive diagram showing Shor's algorithm breaking RSA here") rather than just writing paragraphs.
*   **Sub-task 1.3:** Write the end-of-module assessment quizzes in JSON format, scaling in difficulty from Module 1 to Module 3.

### Phase 2: Security Hardening (Days 4-7)
*   **Sub-task 2.1:** Work with the Data Scientist to implement password hashing (bcrypt) into the Backend API.
*   **Sub-task 2.2:** Build a JWT token generator so users remain logged in securely without storing plain-text passwords in their browser.

### Phase 3: Advanced Scenario Labs (Days 8-10)
*   **Sub-task 3.1:** Create gamified "Escape Room" scenarios (e.g., "A threat actor has stolen your encrypted data today and will decrypt it in 5 years using a quantum computer. Which mitigation strategy do you apply?").
*   **Sub-task 3.2:** Define what "Badges" a user should unlock for completing specific cryptography labs, and give that list to the Frontend Developer.
