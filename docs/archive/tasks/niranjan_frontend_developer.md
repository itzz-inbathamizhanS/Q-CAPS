# Role: UI/UX Frontend Developer
**Team Member:** Niranjan
**Focus:** Extreme Gamification, Visuals, User Experience, React Components

## Exactly What You Need to Build
You are building the visual website that users interact with using React/Vite and Tailwind CSS. **Your main and most important priority is making this platform look heavily GAMIFIED.** It should not look like a boring corporate dashboard; it should look like a cutting-edge video game or hacker simulation. Your final product must include level-up animations, a stylized Leaderboard, an interactive Quiz interface, and a Scanner "Mission Hub."

## How to Use AI to Help You Build It
Since you don't need to write the complex math, you can use AI to write the UI code for you! 
**Example Prompts to give your AI:**
*   *"Write a React component using Tailwind CSS that looks like a high-tech video game menu for a 'Cyber Recon Mission' (which is actually a network scanner). Use neon colors, dark mode, and sleek animations."*
*   *"Create a fake JSON file containing mock user scores, and write a React useEffect hook to load this data into a highly stylized Gamified Leaderboard table."*

## Your Individual Sub-Segmented Plan

### Phase 1: Mock Data & Gamified Layout (Days 1-3)
*   **Sub-task 1.1:** Create a fresh React Vite project.
*   **Sub-task 1.2:** Install `react-router-dom` and build the 5 empty pages: Home, Scanner, Training, Assessment, Profile. Apply a dark, neon-accented gamified theme globally using Tailwind CSS.
*   **Sub-task 1.3:** Create a file called `mockData.json` with fake scores, fake user ranks, and dummy text.

### Phase 2: Building the UI Components (Days 4-7)
*   **Sub-task 2.1:** Build the **Interactive Assessment UI**. Create components that support visual learning aids (images, diagrams) alongside the questions, modeling the Cisco networking academy feel.
*   **Sub-task 2.2:** Build the **Scanner Hub UI**. Make it look like an intense "Mission Control" panel where a user types a URL and clicks a "Launch Recon" button.
*   **Sub-task 2.3:** Build the **Dashboard UI**. Use Chart.js to create a visually appealing graph showing the user's readiness score alongside their unlockable badges.

### Phase 3: Connecting to the Real Backend (Days 8-10)
*   **Sub-task 3.1:** Wait for the Data Scientist to give you the real API URLs.
*   **Sub-task 3.2:** Delete your `mockData.json` file.
*   **Sub-task 3.3:** Replace the fake data with `fetch()` commands to pull real data from the Data Scientist's API, ensuring that the Data Scientist's "Recommendations" are visually highlighted on the user's dashboard.
