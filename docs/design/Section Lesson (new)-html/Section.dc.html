What is happening

Before any page content is sent, the browser and server agree on how to protect it. The server proves who it is with a certificate, and both sides derive a shared secret key that only they know. Everything afterwards is encrypted with that key.

Why this matters for quantum. The key exchange step is what a large quantum computer running Shor's algorithm would break. Post-quantum key exchange replaces it; you will see this in Track B.
